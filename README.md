# # Kidney and Me

## About the Project

Kidney and Me is a health information website designed to make kidney health information easier to find and understand. The website is mainly designed for older adults and people who have recently been diagnosed with a kidney-related condition.

The goal is to organize important information in one place without overwhelming the user with complicated navigation or large amounts of information at once.

## Main Features

The website will include:

* A Start Here page for users who are new to kidney health
* Information about common kidney conditions
* Diet and nutrition information
* Medication information
* Doctor and appointment resources
* Warning signs and symptoms
* Support and trusted health resources
* Quick links and collapsible sections to make information easier to navigate
* Responsive design for desktop and mobile devices

## Technologies

The website is being developed using:

* HTML
* CSS
* JavaScript
* GitHub for version control

## Current Progress

The basic website structure and design have been created. The Home, Start Here, and Kidney Conditions pages are currently being developed. Responsive CSS and quick navigation links have also been added.

Future development will focus on completing the remaining pages, adding more interactive features, and replacing placeholder content with information from reliable medical sources.

## Accessibility

Because the website is intended to be easy to use for older adults, accessibility is an important part of the design. The website will focus on readable text, clear navigation, strong contrast, descriptive headings, and a responsive layout.

## Medical Disclaimer

Kidney and Me is intended for educational purposes only. The information provided on the website is not a replacement for professional medical advice, diagnosis, or treatment. Users should speak with a qualified healthcare professional about medical concerns.
